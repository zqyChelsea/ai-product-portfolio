# Attraction discovery

Present a recognizable shortlist before planning; include Osaka Castle, Universal Studios Japan, Abeno Harukas, Shinsaibashi, Dotonbori, Kaiyukan and Umeda Sky Building. Let travellers pin more than one place, add a custom stop, and type an interest only when the offered tags do not fit. Interest tags narrow suggestions but must never remove pinned places. An unmapped custom interest is recorded and flagged for review, not silently treated as a known category. Mark full-day sites so they are not squeezed between unrelated districts. Store broad districts only as planning hints; verify exact opening hours and ticket prices with licensed/live data before showing them as current. If a custom stop lacks known geography, keep it in an unresolved list rather than pretending to route it.
